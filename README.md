# UC13 - Desenvolvimento Backend com API REST e Integração de Banco de Dados

Bem-vindo(a) à Unidade Curricular **Desenvolvimento Backend com API REST e Integração de Banco de Dados**.

Nesta disciplina construiremos uma API REST completa utilizando **Node.js**, **TypeScript** e **Express**, aplicando boas práticas de desenvolvimento, arquitetura em camadas, integração com banco de dados relacional, autenticação, documentação e testes.

O objetivo é aproximar o desenvolvimento realizado em sala de aula das práticas utilizadas no mercado de trabalho.

---

# Objetivos da Unidade Curricular

Ao final desta UC, você será capaz de:

* Desenvolver APIs REST utilizando Node.js e TypeScript;
* Aplicar arquitetura em camadas (Controller, Service e Repository);
* Integrar aplicações com bancos de dados relacionais;
* Utilizar ORM para persistência dos dados;
* Implementar autenticação e autorização;
* Validar dados recebidos pela API;
* Tratar erros de forma centralizada;
* Documentar APIs;
* Aplicar boas práticas de organização de projetos;
* Consumir a API a partir de aplicações Front-end.
